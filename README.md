# Portfolio

Personal developer portfolio: about, skills, experience, projects and a working contact form.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · next-themes (light/dark) · Resend (contact emails)

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Environment

Create `.env.local`:

```
RESEND_API_KEY=your_resend_key
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Dev server (Turbopack) |
| `npm run build` | Production build |
| `npm start` | Serve the build |
| `npm run lint` | Lint |
